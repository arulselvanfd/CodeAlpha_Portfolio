Projects
Four builds, three live and one local. Tap a card to expand.
batWEBAI-powered website intelligence platform
Live project ↗

Points a vision LLM at a website's screenshot and returns real usability, accessibility, and performance verdicts. Built a custom BWscore, a radar-chart analytics dashboard, and exportable technical PDF reports covering Core Web Vitals and semantic HTML.

React.jsViteTailwind CSS Framer MotionOpenRouter Vision API
Screenshots are sent to a vision-capable model via OpenRouter, which returns structured findings on layout, contrast, and semantic markup. Those findings feed a weighted scoring function (BWscore) and render into a radar chart plus a downloadable PDF report — the same pattern used for the skill chart on this page.
batHouseSocial networking & messaging platform
Live project ↗

A responsive one-to-one messaging app with image and video sharing. Firebase Auth and Firestore handle identity and data; Context API and React Router manage state and navigation. Packaged as a PWA and converted to an Android app via PWABuilder.

React.jsFirebaseCloudinary Context APINetlifyPWABuilder
Media uploads route through Cloudinary for compression and delivery, while Firestore listeners keep conversations in sync in real time. The same PWA manifest that runs it in-browser was wrapped through PWABuilder to produce an installable Android package.
NASC Online VotingDigital election platform for department elections
Live project ↗

Deployed a real digital ballot for college department elections — 280+ students voted through it. Firebase Auth and Firestore secured access and vote data; the interface stayed simple enough that nobody needed instructions.

React.jsTailwind CSSFirebaseNetlify
One-vote-per-student was enforced with Firebase Auth tied to college email, and Firestore security rules blocked duplicate ballots at the database layer rather than trusting the client. Results were tallied live and locked at the close of polling.
BatwavePodcast submission & sharing platform

A podcast platform where users submit episodes and admins review before publishing — a small but complete content workflow, built with vanilla JS and Firebase before I moved to React.

HTML5CSS3JavaScriptFirebase
Built pre-React, using vanilla JS to manage submission state and an admin-only approval queue backed by Firebase — the project that pushed me toward component-based frameworks for the next build.
